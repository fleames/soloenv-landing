Features

Everything a solo dev needs. Nothing a platform team would.

One command

soloenv up builds, runs, and exposes your app. No YAML rabbit holes.

Your Docker workflow

Compose or Dockerfile — no rewrites, no framework lock-in.

Password protection

--protect adds HTTP basic auth before anyone hits your WIP app.

Auto teardown

--ttl 4h expires the environment. No zombie tunnels overnight.

Detached mode

Close your terminal — staging keeps running until you say down.

PR previews beta

Drop-in GitHub Action posts a preview URL on every pull request.

FAQ

Questions, answered.

Is SoloEnv live?

Yes — CLI v0.2 is on GitHub. This page is part of our validation experiment to measure broader demand.

How do I install it?

Download from Releases, or run go install github.com/fleames/soloenv-cli@latest. Requires Docker.

Who is this for?

Solo founders, indie hackers, and freelancers shipping web apps with Docker who want staging without a platform team.

Does it cost anything?

SoloEnv is free and open source. Quick tunnels use Cloudflare's free tier — no account required to start.
